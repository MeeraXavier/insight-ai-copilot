# InsightAI — Customer Analytics Copilot

An AI-powered customer analytics platform built with React, TypeScript, Python, and FastAPI. This project explores how machine learning and Generative AI can help transform customer feedback into actionable insights.

## 🎯 Project Goals

- Analyze customer feedback and identify common themes.
- Explore sentiment analysis using machine learning.
- Generate concise summaries of customer feedback using LLMs.
- Visualize customer insights through an interactive dashboard.
- Build practical experience with AI engineering, data processing, and API development.

## 🛠️ Tech Stack

**Frontend**
- React
- TypeScript
- Data visualization

**Backend**
- Python
- FastAPI
- Pydantic

**Data & AI**
- Pandas and NumPy
- Machine learning with scikit-learn
- Large Language Models (LLMs)
- Embeddings and Retrieval-Augmented Generation (RAG)

*Technologies will be introduced incrementally as the project develops.*
